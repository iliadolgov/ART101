23. Show a temporary response

How it works

A click shows the message and schedules its removal after two seconds. Another click cancels the earlier timeout and starts a new one, so the message gets the full duration after the latest click.

Example

Open example separately

Key interaction

Code excerpt — full code below.

// Save the timer ID so a later click can cancel the pending hide.
let hideTimer = null;

// .click(...) runs this function when Show message is clicked.
$("#show-button").click(function () {
    clearTimeout(hideTimer);
    $("#message").text("Message shown.");

    // Run this function once after 2000 milliseconds (2 seconds).
    hideTimer = setTimeout(function () {
        $("#message").text("");
    }, 2000);
});

Try changing 2000 to 5000. Click twice a few seconds apart and check when the message disappears.
