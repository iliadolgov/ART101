24. Start and stop a countdown

How it works

Start runs one tick each second. Stop keeps the remaining time, and Start continues from there. Repeated Start clicks do not create extra intervals. At zero, the interval stops itself; Reset restores the starting value.

Example

Open example separately

Key interaction

Code excerpt — full code below.

let startingSeconds = 5;
let seconds = startingSeconds;
// null means there is no running interval.
let timer = null;
$("#seconds").text(seconds);

// .click(...) runs this function when Start is clicked.
$("#start-button").click(function () {
    // Start only one interval, and only while time remains.
    if (timer == null && seconds > 0) {
        // Repeat this function every 1000 milliseconds (1 second).
        timer = setInterval(function () {
            seconds = seconds - 1;
            $("#seconds").text(seconds);
            if (seconds == 0) {
                clearInterval(timer);
                timer = null;
            }
        }, 1000);
    }
});

$("#stop-button").click(function () {
    // Stop ticking but keep the remaining seconds for the next Start.
    clearInterval(timer);
    timer = null;
});

Try clicking Start several times while counting: it should still lose only one second per second. Stop before zero, wait, then click Start; it should continue from the saved value. Let it reach zero and check that it stays there.
