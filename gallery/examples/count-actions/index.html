5. Count actions and change the response

How it works

Each click adds one to count. The response changes when the count reaches threshold and stays changed as the count keeps growing.

Example

Open example separately

Key interaction

Code excerpt — full code below.

// Outside the handler so the count is remembered between clicks.
let count = 0;
let threshold = 5;

// .click(...) runs this function when #count-button is clicked.
$("#count-button").click(function () {
    // Add one before displaying or checking the updated count.
    count = count + 1;
    $("#count").text(count);

    // >= means greater than or equal to, so this also works past the threshold.
    if (count >= threshold) {
        $("#result").text("Threshold reached.");
    }
    else {
        $("#result").text("Below the threshold.");
    }
});

Try changing threshold from 5 to 3.
