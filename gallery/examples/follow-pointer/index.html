20. Follow the pointer

How it works

The button switches following on or off. Pointer movement updates the same dot only while following is on. Subtracting the area’s position converts page coordinates into positions inside it.

Example

Open example separately

Key interaction

Code excerpt — full code below.

// Keep the mode outside the handlers so both events can use it.
let following = false;

// .click(...) runs this function when Start following is clicked.
$("#toggle-button").click(function () {
    // ! flips true to false, or false to true.
    following = !following;
    if (following == true) {
        $("#toggle-button").text("Stop following");
    }
    else {
        $("#toggle-button").text("Start following");
    }
});

// event supplies the pointer position for this movement.
$("#stage").mousemove(function (event) {
    if (following == true) {
        // Subtract the area's page position to get coordinates inside it.
        let x = event.pageX - $("#stage").offset().left;
        let y = event.pageY - $("#stage").offset().top;
        $("#dot").css("left", x);
        $("#dot").css("top", y);
    }
});

Try adding 20 to x when setting left. The dot will follow beside the pointer.

follow-pointer.css

* { box-sizing: border-box; }
body { margin: 24px; font-family: Arial, sans-serif; color: #333; background: white; }
p { line-height: 1.5; }
button { padding: 10px 16px; border: 1px solid #888; background: #f7f7f5; font: inherit; cursor: pointer; }
.controls { display: flex; flex-wrap: wrap; gap: 10px; }

/* This relative container is the origin for its absolutely positioned child: left/top are local to it. */
#stage { position: relative; width: 100%; height: 220px; margin-top: 24px; background: #f7f7f5; outline: 1px solid #aaa; overflow: hidden; }

/* Shift back by half the mark's own size to center it on the coordinates. */
.mark { position: absolute; width: 20px; height: 20px; border: 1px solid #555; border-radius: 50%; background: #aaa; transform: translate(-50%, -50%); }
/* Marks do not intercept later pointer events. */
.mark { pointer-events: none; }

#dot { left: 80px; top: 80px; }
