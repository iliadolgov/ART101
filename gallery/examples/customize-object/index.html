14. Customize an object

How it works

The controls hold a label, color and shape. Clicking Apply reads all three with .val(), then updates the same object using .text(), .css() and a shape class. Editing a control does not change the preview until Apply is clicked.

Example

Open example separately

Key interaction

Code excerpt — full code below.

// .click(...) runs this function when #apply-button is clicked.
$("#apply-button").click(function () {
    // .val() reads a control's current value when Apply is clicked.
    let objectLabel = $("#object-label").val();
    let objectColor = $("#object-color").val();
    let objectShape = $("#object-shape").val();

    // .text(...) shows the label literally, including < and >.
    $("#preview-label").text(objectLabel);
    // .css(property, value) changes this object's background color.
    $("#object").css("background-color", objectColor);

    // Remove the old shape class, then add the chosen one.
    $("#object").removeClass("square circle");
    $("#object").addClass(objectShape);
});

Try adding a rounded-square option. Give it a CSS class, use that class name as the option value, and include it in the classes removed before applying a new shape.

customize-object.html

<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Customize an object</title>
    <link rel="stylesheet" href="customize-object.css">
    <script src="jquery-3.7.1.min.js"></script>
    <script src="customize-object.js" defer></script>
</head>
<body>
    <p>Choose a label, color and shape, then click Apply.</p>
    <label for="object-label">Label</label>
    <input id="object-label" type="text" value="Example" maxlength="16">
    <div id="options">
        <div>
            <label for="object-color">Color</label>
            <input id="object-color" type="color" value="#d9d9d3">
        </div>
        <div>
            <label for="object-shape">Shape</label>
            <!-- The option values match the CSS class names. -->
            <select id="object-shape">
                <option value="square">Square</option>
                <option value="circle">Circle</option>
            </select>
        </div>
    </div>
    <button id="apply-button" type="button">Apply</button>
    <div id="object" class="square">
        <span id="preview-label" aria-live="polite">Example</span>
    </div>
</body>
</html>
