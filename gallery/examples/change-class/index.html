2. Change a class

How it works

.toggleClass("changed") adds the class on one click and removes it on the next. The CSS rule #element.changed describes how the element looks when it has that class.

Example

Open example separately

Key interaction

Code excerpt — full code below.

// $("#change-button") selects the button by its HTML ID.
// .click(...) runs this function each time that button is clicked.
$("#change-button").click(function () {
    // .toggleClass(...) switches the "changed" CSS class on or off.
    // The CSS rule #element.changed supplies its appearance.
    $("#element").toggleClass("changed");
});

change-class.css

/* Apply these styles only while #element has the changed class. */
#element.changed {
    border-color: #333;
    border-radius: 50%;
    background: #777;
    color: white;
}

Try changing border-radius: 50% to border-radius: 12px in the CSS.
