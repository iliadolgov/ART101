15. Create an item from input

How it works

Add reads the label, creates a new list item, and appends it to the existing list. .text() keeps the label as literal text. A successful addition clears the field for the next item.

Example

Open example separately

Key interaction

Code excerpt — full code below.

// .click(...) runs this function when the Add button is clicked.
$("#add-button").click(function () {
    // .val() reads the field; .trim() removes spaces at either end.
    let label = $("#item-label").val().trim();

    if (label == "") {
        $("#message").text("Enter a label.");
    }
    else {
        // HTML inside $(...) creates a new element, not yet on the page.
        let item = $("<li></li>");
        // .text(...) sets its label literally, including < and >.
        item.text(label);
        // .append(...) adds it after the existing list items.
        $("#items").append(item);
        // Clear the field and return focus for the next item.
        $("#item-label").val("");
        $("#item-label").focus();
        $("#message").text("");
    }
});

Try replacing .append(item) with .prepend(item) to place each new item first.
