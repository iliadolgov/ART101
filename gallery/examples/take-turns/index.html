13. Take turns

How it works

turn remembers who may act. An allowed click records that action and gives the turn to the other participant. Clicking out of turn shows a reminder and leaves the turn unchanged.

Example

Open example separately

Key interaction

Code excerpt — full code below.

// Keep the current turn outside the handlers so both buttons can check it.
let turn = "A";
$("#turn").text(turn + "'s turn.");

// .click(...) runs this function when #button-a is clicked.
$("#button-a").click(function () {
    // == compares the current turn with "A".
    if (turn == "A") {
        $("#result").text("A took a turn.");
        // = assigns a new value, giving the next turn to B.
        turn = "B";
        $("#turn").text("B's turn.");
    }
    else {
        // An out-of-turn click gives feedback without changing turn.
        $("#result").text("Wait for B.");
    }
});

Add an A or B mark to a separate output inside each permitted if branch, before handing over the turn. Try an out-of-turn click: it should show the existing wait message without adding a mark.
