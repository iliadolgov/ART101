# ART101 debugging Garden — instructor package

Start with instructor-notes.md. The five strategies stay in their agreed order.

Extract this package before opening it. Each exercise folder is independent: open its index.html in your browser and garden.js in VS Code. Keep jquery-3.7.1.min.js, style.css and index.html alongside garden.js.

Show 00-working first. Use 01–05 for the guided demonstrations. Give teams only team-challenge for the final practice; its README states expected behaviour without giving solutions.

Use simple names such as Moss, Fern and Clover. The code deliberately uses the small set of class patterns needed for the debugging lesson.

jQuery 3.7.1 is bundled unchanged from code.jquery.com, with its license notice intact.
