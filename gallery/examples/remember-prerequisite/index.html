10. Remember a prerequisite

How it works

Prepare sets isReady to true. Use checks that remembered value, so it works only after preparation. The value stays true for later uses.

Example

Open example separately

Key interaction

Code excerpt — full code below.

// A Boolean is true or false. Keep it outside the handlers to remember it.
let isReady = false;

// .click(...) runs this function when #prepare-button is clicked.
$("#prepare-button").click(function () {
    isReady = true;
    $("#result").text("Prepared. You can use it now.");
});

$("#use-button").click(function () {
    // Check the value saved by the earlier action.
    if (isReady == true) {
        $("#result").text("Used.");
    }
    else {
        $("#result").text("Prepare it first.");
    }
});

Try adding isReady = false; after a successful use. Preparation will then be needed before each use.
