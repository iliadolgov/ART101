3. Reveal on hover

How it works

Moving onto the item shows its note; moving away hides it. .hover() receives those two functions in that order. Use a mouse or trackpad.

Example

Open example separately

Key interaction

Code excerpt — full code below.

// .hover(...) takes two functions: entering first, leaving second.
$("#item").hover(
    function () {
        // Show the note when the pointer enters the item.
        $("#note").show();
    },
    function () {
        // Hide it again when the pointer leaves.
        $("#note").hide();
    }
);

Try replacing the note’s text with an image. The same show and hide calls can reveal a preview.
