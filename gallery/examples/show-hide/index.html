1. Show and hide

How it works

The element starts hidden because its CSS has display: none. Clicking Show runs .show(); clicking Hide runs .hide(). Both buttons act on the same element.

Example

Open example separately

Key interaction

Code excerpt — full code below.

// $("#show-button") selects the button by its HTML ID.
// .click(...) runs this function each time that button is clicked.
$("#show-button").click(function () {
    // .show() makes #element visible, overriding its initial display: none.
    $("#element").show();
});

// Run this function when the Hide button is clicked.
$("#hide-button").click(function () {
    // .hide() hides the element without removing it from the HTML.
    $("#element").hide();
});

Try replacing the text inside the element with an image. The same buttons will show and hide it.

show-hide.html

<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Show and hide</title>
    <link rel="stylesheet" href="show-hide.css">
    <script src="jquery-3.7.1.min.js"></script>
    <script src="show-hide.js" defer></script>
</head>
<body>
    <p>Show the element, then hide it again.</p>
    <div id="controls">
        <button id="show-button">Show</button>
        <button id="hide-button">Hide</button>
    </div>
    <div id="stage">
        <div id="element">Here I am.</div>
    </div>
</body>
</html>

show-hide.css

body {
    margin: 24px;
    font-family: Arial, sans-serif;
    color: #333;
    background: white;
}

p { line-height: 1.5; }

button {
    padding: 10px 18px;
    border: 1px solid #777;
    border-radius: 3px;
    background: #f2f2f0;
    color: #333;
    font-size: 14px;
    cursor: pointer;
}

#controls { display: flex; gap: 10px; }

/* Keep space for the element even while it is hidden. */
#stage { margin-top: 28px; min-height: 110px; }

#element {
    display: none; /* The element starts hidden. */
    padding: 30px;
    border: 1px solid #888;
    background: #e7e7e3;
    text-align: center;
}
