ART101 Teaching Examples

Explore the class examples below, grouped by the ideas they introduce.

General patterns

  • The Gallery — Numerous basic interactions and complex patterns to feed your projects
  • The Garden — Gallery based project

HTML and CSS

  • The Pancakes Universe: recipe homepage — Image links, absolute positioning, animated backgrounds, and a custom font.
  • The Pancakes Universe: recipe detail page — Shared styles, an image gallery, and relative links between pages and folders.

JavaScript and interaction

  • Exercise 04: Color and mood clicker — Use jQuery click events, variables, arrays, and conditionals to count clicks, cycle background colors, and add mood messages.
  • Exercise 05: Color picker and reusable functions — Use a paintPage(color) function to change the background from the clicker button or a row of clickable circles.
  • Jake and Finn: click-through conversation — Click the characters to advance dialogue using message arrays and counters, then choose a color to change the background and the reply.
