25. Control a sound

How it works

Play starts or resumes the sound. Pause keeps its current position; Stop pauses and moves back to the beginning. The status follows the audio’s playback events.

Example

Open example separately

Key interaction

Code excerpt — full code below.

// jQuery returns a collection; [0] gets the audio element itself.
let sound = $("#sound")[0];

// .click(...) runs this function when Play is clicked.
$("#play-button").click(function () {
    sound.play(); // Start or resume from the current position.
});

$("#pause-button").click(function () {
    sound.pause(); // Keep the current playback position.
});

$("#stop-button").click(function () {
    sound.pause();
    sound.currentTime = 0; // Playback positions are measured in seconds.
    $("#status").text("Not playing.");
});

Pause partway through the four ascending notes, then press Play and notice where playback continues. Repeat with Stop, then Play: the sound returns to the first note. Compare keeping the playback position with resetting it to zero.

control-sound.js

// jQuery returns a collection; [0] gets the audio element itself.
let sound = $("#sound")[0];

// .click(...) runs this function when Play is clicked.
$("#play-button").click(function () {
    sound.play(); // Start or resume from the current position.
});

$("#pause-button").click(function () {
    sound.pause(); // Keep the current playback position.
});

$("#stop-button").click(function () {
    sound.pause();
    sound.currentTime = 0; // Playback positions are measured in seconds.
    $("#status").text("Not playing.");
});

// These events report the audio's state, not just a button click.
$("#sound").on("playing", function () {
    $("#status").text("Playing.");
});
$("#sound").on("pause", function () {
    $("#status").text("Not playing.");
});
$("#sound").on("ended", function () {
    $("#status").text("Finished.");
});
